COPIAR PARA O HOST
Adicione apenas a tag <script> no HTML do seu sistema. O widget carrega automaticamente, fica flutuante e expõe window.__maya.
<!-- Adicionar antes de </body> --> <script src="http://localhost:3000/maya-widget.js" data-position="right" data-theme="#00d4ff" ></script> // API pública exposta: window.__maya.enrollVoice(name, userId) // enrollment de voz window.__maya.open() // abrir widget window.__maya.on('enroll-complete', fn) // escutar resultado window.__maya.on('open-change', fn) // abrir/fechar window.__maya.off('enroll-complete', fn) // remover listener
