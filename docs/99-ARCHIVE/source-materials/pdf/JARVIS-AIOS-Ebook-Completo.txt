Instalar o Claude Code
Única instalação manual necessária — leva 5 minutos
Claude Code é a ferramenta que você vai usar para construir tudo. É um
programa que roda no terminal do seu computador e executa comandos por
você.
Pré-requisitos
1
Node.js instalado
Baixe em
nodejs.org
→ versão LTS (botão verde). Instale normalmente como qualquer
programa Windows.
2
Conta na Anthropic criada
Acesse
console.anthropic.com
→ crie sua conta → gere uma API Key em "API Keys"
Instalar o Claude Code
Abra o Prompt de Comando (CMD) ou PowerShell e execute:
> npm install -g @anthropic-ai/claude-code
> claude
# Na primeira execução, vai pedir para fazer login
# Pressione Enter, abra o link no browser e autorize
▶ COMO SABER QUE FUNCIONOU
Você verá o prompt claude> ou uma interface de chat no terminal. Digite "olá" e
Claude responde. Está pronto.

"JARVIS" ativa a voz — ele só responde quando chamado pelo nome
▶COMANDO 06 — Cole no Claude Code
Implemente o sistema de voz completo do JARVIS com OpenAI Realtime 
API. Crie:
1. src/app/api/realtime-token/route.ts — gera token efêmero POST para 
https://api.openai.com/v1/realtime/sessions usando OPENAI_API_KEY
2. src/lib/realtimeClient.ts — cliente WebSocket que conecta ao 
endpoint wss://api.openai.com/v1/realtime?model=gpt-4o-realtime-
preview, emite eventos tipados
3. src/hooks/useAudioCapture.ts — captura microfone via getUserMedia, 
converte para PCM16 em chunks de 100ms via ScriptProcessor, emite 
base64
4. src/hooks/useAudioPlayback.ts — reproduz chunks de áudio PCM16 
recebidos via AudioContext, controla barge-in (parar quando usuário 
fala)
5. src/hooks/useWakeWord.ts — usa Web Speech API (SpeechRecognition) 
em modo contínuo, detecta "jarvis" no transcript, captura o comando 
depois do wake word, IMPORTANTE: create_response deve ser false por 
padrão (JARVIS não responde a qualquer fala, só quando chamado)
6. src/hooks/useRealtimeSession.ts — orquestra tudo: conecta 
WebSocket, configura session.update com turn_detection 
create_response: false, gerencia estados 
'idle'|'connecting'|'active'|'thinking'|'speaking', implementa 
conversation mode de 30s após wake word
7. Integre no JarvisCockpit: botão " MIC ATIVO /  MIC MUDO" no 
centro, orbe que reage ao áudio, indicador de estado de voz
Confirme que ao dizer "JARVIS, qual a hora?" a voz é detectada e 
JARVIS responde.

O CÉREBRO — Multi-IA para máxima qualidade
O CÉREBRO é o motor de síntese que combina múltiplas IAs em uma única
resposta. Quando ativado, envia a mesma tarefa para Claude, Gemini e Llama
simultaneamente e sintetiza o melhor de cada resposta — resultando em
qualidade muito superior a qualquer modelo sozinho.
Configure o ORÁCULO para pesquisar sobre os tópicos mais relevantes 
para o meu negócio. Adicione os seguintes temas de pesquisa ao array 
ORACULO_TOPICS no arquivo src/app/api/oraculo/route.ts (ou 
equivalente): tendências de IA para [meu setor], ferramentas e 
automações para [meu nicho], cases de sucesso de [tipo de negócio], 
novidades em modelos de linguagem e suas aplicações práticas, 
oportunidades de mercado em [área de interesse].
Também configure o ORÁCULO para salvar um resumo semanal consolidado 
em um arquivo "briefing-semanal.md" na aba DOCS toda segunda-feira às 
8h via cron na Vercel.
