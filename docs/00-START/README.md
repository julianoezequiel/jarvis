## 🎯 Que Tipo de Informação Você Procura?

### "O que é e como funciona?"
1. Leia [`QUICK_START.md`](./QUICK_START.md) (visão geral)
2. Explore [`01-PRODUCT/VISION.md`](../01-PRODUCT/VISION.md) (o quê e por quê)

1. Leia [`03-DEVELOPMENT/SETUP.md`](../03-DEVELOPMENT/SETUP.md) (install)
2. Siga [`03-DEVELOPMENT/QUICKSTART_DEV.md`](../03-DEVELOPMENT/QUICKSTART_DEV.md) (primeiros passos)

### "Quero uma trilha completa de implementação"

3. Valide cada fase com [`03-DEVELOPMENT/WORKFLOW_TASKS.md`](../03-DEVELOPMENT/WORKFLOW_TASKS.md)

### "Como faço uma task?"
1. Veja [`03-DEVELOPMENT/WORKFLOW_TASKS.md`](../03-DEVELOPMENT/WORKFLOW_TASKS.md)
2. Use templates em [`03-DEVELOPMENT/templates/`](../03-DEVELOPMENT/templates/)

2. Explore payloads em [`04-API-REFERENCE/schemas/`](../04-API-REFERENCE/schemas/)

### "Como faço deploy?"
1. Leia [`05-DEPLOYMENT/VERCEL.md`](../05-DEPLOYMENT/VERCEL.md)
2. Consulte [`05-DEPLOYMENT/RUNBOOKS.md`](../05-DEPLOYMENT/RUNBOOKS.md)
