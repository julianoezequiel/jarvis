# Tasks Documentadas

Esta pasta concentra exemplos e registros de tasks concluídas ou em andamento.

## Estrutura

Cada task deve seguir o padrão:

```text
jarvis-TASK-XXX/
├── ANDAMENTO.md
├── ANALISE.md
└── CRITERIOS_ACEITE.md
```

## Exemplo disponível

- `jarvis-TASK-001/`

## Uso recomendado

- use `templates/` para iniciar uma nova task
- use `tasks/` para armazenar a documentação real da task
